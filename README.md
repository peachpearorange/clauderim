# Northmark

![Wanderer on a snowy summit overlooking the mountains](docs/screenshot.webp)

**Play in the browser: https://peachpearorange.github.io/clauderim/** (needs WebGPU — Chrome or Edge; click for fullscreen)

A procedural Nordic wilderness in Bevy: a horned-helmet wanderer, wolves, barrow wights, bandits, barrows, a rune wall and a dragon. No mesh or texture assets — everything is generated.

Run locally with `cargo run`.

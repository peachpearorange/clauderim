# Skyrim II
A Bevy 0.19.1 game meant to pass, for five minutes, as "Skyrim 2": a ~6 km Nordic world around a starting valley, with stone roads, towns, a walled city, farms, rivers and lakes with a mill and bridges, bandit forts, and ~300 scattered camps, ruins, barrows, caves, shrines and homesteads; a horned-helmet Dragonborn with sword and shield, wolves, draugr, bandits, caves/barrows, a word wall, a dragon. Everything is procedural: no mesh or texture assets. Only fonts live in `assets/fonts`. `ref images/` holds Skyrim screenshots to match the look against (incl. the world map, with and without markers, for density).

# Modules
- `terrain.rs` — streamed heightfield world (`WORLD` = ±3072 m playable, far lands to ±12 km). `height_at` is the pure function (natural land → road grading → place flattening → river carve); Snow paint: white above a wobbly snow line except on steep faces. `Ground` resource is a lazily filled cache of 128 m chunks on the 2 m grid (`height`, `normal`, `surface`, `chunk_at`); `Footing` streams heightfield colliders within ~340 m of the player (`firm(at)`; walkers on unloaded ground rest). Render meshes are a camera-centred quadtree of 64×64-cell tiles (2 m near, coarser far), rebuilt in background tasks nearest-first; each group of stale tiles is swapped as soon as the new tiles covering it are ready, so the ground under the player never lags at a coarse LOD. `forest(at)` density, lake. `paint` returns a `Cover`: vertex tint plus weights of six `Layer`s (Grass, Litter, Dirt, Gravel, Rock, Snow; UV_0 = litter/dirt, UV_1 = gravel/rock, colour alpha = snow, grass is the rest). The `Land` material (`StandardMaterial` + `Layers` extension, `terrain.wgsl`) splats their detail textures (`texture::land()`, a 2D array of tone+height and normal+roughness) by height-blending, world-space UVs with a rotated second sample against tiling, rock triplanar, snow biased to cover.
- `place.rs` — `Place` is an index into the named places (`Place::KJELDHOLM` … consts, `Spot { name, at, marker, flat, sunk, rise }`) followed by the generated `site::SITES`; `place::named()` (safe inside terrain/road/layout `LazyLock`s), `sites()`, `all()`, binned `around(at)` (use it in per-sample code). Markers incl. `Town/City/Farm/Fort/Ruin/Shack/Shrine`. `START`, `ROADS` network (`Paving::Stone|Dirt`, spline-smoothed, then `wandered` by a world-space noise field that fades near named places so junctions stay joined; includes named settlement streets), binned `nearest_road`, `road_distance`, `route_distance` (all ways incl. trails); `pass_distance` (main `ROADS` only: mountain passes follow them, and `natural_height` depends on it) and `nearest_main_road`. `TRAILS` (`Paving::Trail`) climb from main roads to highland barrows, routed by `trail::Climb`; `ways()` = roads + trails (bridges, paint, grading). Trails can't feed back into `natural_height` or site generation.
- `trail.rs` — barrow trails are baked: `trail_cells.rs` (generated) holds each trail's 14 m grid cells, `laid` Chaikin-smooths them at load. `survey::Climb { from, reach, steepest }.toward(remaining)` (test-only) is the A* over `natural_height` (16 moves, grade limit, turn and ford penalties) that produced them; `cargo test trails_are_current` (~5 s) fails when terrain or sites change — then rebake with `cargo test --features dev bake_trails -- --ignored`.
- `site.rs` — ~300 minor places (camps, shacks, homesteads, watchtowers, ruins, barrow mounds, wolf caves, wayshrines, stone circles) scattered on a jittered grid over gentle ground away from roads, rivers, lakes and named places, with generated names; barrows are mostly highland sites on the highest acceptable spot (up to `PEAK`) so they show on the mountains, ~35% are sunken ring pits (`sunk`). Bluffs keep clear of places. Built from `settlement::SITE_LAYOUTS`. Generation may only use `natural_height`/main roads (`nearest_main_road`)/river courses (never `height_at` or `place::all`), or the `LazyLock`s deadlock.
- `paving.rs` — cobblestone ribbon meshes laid on stone roads (the terrain paint only reads at a distance). Rounded stones drop out where `decay(at)` (world-space patches, also used by the terrain paint) and along ragged edges: texture alpha holds a per-stone threshold, vertex alpha the wear.
- `river.rs` — water: `BASINS` lakes (levels from the surrounding rim, `lake_near`, `lakes()`), rivers traced from a drainage grid (`DRAINAGE`: priority-flood of `terrain::land(at, 1.0)` on 24 m cells seeded at the lakes, settlements bumped up so water skirts them; cells whose catchment exceeds `SPRING_AREA` become `COURSES` into lakes or other rivers, Chaikin-smoothed and meandered `PATHS`, widths from catchment, monotone `LEVELS` clamped to the mouth), `carve` (valley + channel per river), `water_level(at)` (used for swimming), water ribbons, lake planes, `BRIDGES` where roads cross (deck from both banks; `ramp` raises the road ground up to the deck, `deck(at)` for paving). Drainage must not touch roads/places `LazyLock`s. `cargo test --features dev levels -- --ignored --nocapture` prints courses, bridges and levels; rivers must run downhill between lakes.
- `settlement.rs` — `LAYOUTS` (named, pure 2D plans: `town`, `city`, `farm`, `fort` → `Work`s, streets, worn ground, fields, foes) and `SITE_LAYOUTS` (`camp`, `shack`, `watch`, `ruin`, `barrow` (receding stone tiers with ragged parapets + rib-arched portal, terrace with broken arches, or sunken ring pit with alcoves; eagle-headed `Spire`s with braziers), `lair`, `wayshrine`, `stones`; their streets are not roads) and builders (`house` with thatch/shingle/gilded roofs and timber/log/stone/`Jettied` (stone ground storey, timber upper storey on a jetty) walls, `longhall` (town hall: gable entrance, porch, braziers), `inn` (jettied, hanging sign), `forge` (lean-to smithy: hearth with embers, anvil, grindstone, trough, weapon rack), `temple` (stone nave with portico and round steeple), placed by `Plan::settle` facing the nearest street, rampart, round tower, gate, keep, windmill, waterwheel mill, well, wattle fence, crop field, clutter, `stable` with horses outside the city gate, paddock `Horse`). Settlements are raised in background tasks within 2.6 km of the camera; colliders are cuboid/cylinder compounds.
- `sky.rs` — physical atmosphere, sun/moon cycle, `Daylight { level, shelter, snap }`. Set `shelter` toward 1 while the player is underground; exposure and ambient follow it (`snap` > 0 skips eye adaptation, e.g. after a load door).
- `blur.rs` + `blur.wgsl` — distance blur: a post-process pass (after bloom, before tonemapping) that disc-blurs pixels by their depth (`DistanceBlur { from, to, spread }` on the camera, set in `sky::lens`; spread in px at 1080p), weighting taps by their own softness so near edges don't bleed. The camera uses TAA (not SMAA) so thin distant foliage doesn't shimmer; materials with custom vertex shaders need a matching prepass shader or `enable_prepass() -> false` (grass `Sway`), and camera cuts reset TAA history via `Daylight::snap`.
- `mist.rs` + `mist.wgsl` — mist banks clinging to mountain slopes: ~2000 billboards in one mesh (vertex shader turns each toward the camera position, upright, not the view direction, so they do not spin as the camera turns; each carries its local ground plane so it fades where it meets terrain), placed in a background job, lit by `cloud::lighting`.
- `cloud.rs` + `cloud.wgsl` — procedural cloud layer (embedded shader on a plane at 1.9 km, premultiplied alpha), lit from `sky::toward_sun/toward_moon` with sunset reddening and dim at night; behind the clouds the same shader draws stars, the Milky Way and aurora curtains in the north (strength varies per night, `Clock::night`).
- `model.rs` — mesh toolkit: `Piece::new(mesh, color)` then `.at/.sized/.pitched/.yawed/.rolled/.span/.mirrored/.shaded`, `merge(pieces)`, shapes `lathe`, `tube` + `curve` + `taper`, `lump` (noisy flat-shaded rock), `hewn` (plane-cut rock), `crag` (cluster of leaning, peaked rock `Blade`s: `carved(detail)` with vertical fracture grooves, or `hull()`, the exact low-poly polyhedron of its planes, used for the far LOD and colliders; creased normals and face-projected UVs), `blade`, `fan`, `ball`, `block`, `rod`, `cone`; organic: `loft` (stacked `Hoop` rings), `sweep` (along a curved spine), `spline`, `sculpt` (spline + sweep), `ruffled` (fur/scale noise), `sheet` (membranes).
- `stuff.rs` — material palette `Stuff` (Skin, Fur, Leather, Cloth, Iron, Steel, Gold, Bone, Wood, Bark, Birch, Needles, Stone, Cliff, Frost, Ember, Gloss, Membrane, Cinder, Thatch, Shingle, Masonry, Planks); `Stuffs::of(stuff)` gives the shared material. Vertex colour tints; the material adds grain texture. Use `Piece::planar(tile)` / `tiled` for world-scale UVs (trunks: `flora::barked`, ~1 m tiles). `bumpy()` stuffs have normal maps: pass merged meshes through `stuff.fitted(mesh)` (adds tangents) or the relief is silently ignored.
- `texture.rs` — tiling procedural textures, generated in parallel with full mip chains (`unmipped` only for alpha-tested cobbles). A `Texel { tone, height, rough }` function becomes a `Textured { tone, relief }` pair (`textured`, or `stacked` into an array); tone alpha holds height, relief alpha roughness. `Strokes` scatters blades/needles/twigs; `voronoi` for pebbles and plates. Coursed rubble `masonry_stone` (chipped stones, mortar, moss), lichened `rough_stone`, furrowed `pine_bark`, `birch_bark`, the six terrain layers, `cliff`. `cargo test --features dev swatches -- --ignored` writes lit tiles to `screenshots/land.png` / `stuff.png` in seconds — iterate there before in-game shots.
- `humanoid.rs` — jointed rig (11 joints), `Motion` drives procedural poses (`Grip::Bare` = relaxed unarmed stance), outfits `dragonborn/draugr/bandit` and `villager(Calling, &Person)` (innkeeper, huntress, priest, farmer, sellsword; `WOMAN` frame) built as `Kit`s. Bodies are skinned: `tailor(kit, &frame)` (pure, run in a background task) moves every piece into bind space and weights it to its joint, blending with the parent/child joint near each pivot (`Joint::seam`), so limbs bend without gaps; `Kit::held` pieces (weapons, shield, torch) stay rigid. Output is one `SkinnedMesh` per material (head pieces separate, so first person can hide them) spawned by `dress`; `fasten` is the rigid variant (wolves). Cloth uses `Piece::creased` (fold displacement + cavity shading) so garments don't read as smooth plastic.
- `face.rs` — heads. `Race` (Nord, Orc, HighElf, DarkElf, Argonian; `Race::of(seed)` for townsfolk and bandits) and `Person::roll(race, woman, seed)` (skin/hair/eye colours, `Style` of hair, `Beard`, war `Paint`, age, `Visage` proportions; `Person::draugr`). `head` sculpts a dense superellipse head grid (`Skull`, finer rows across the face) displaced by gaussian `Bump`s (brow, eye sockets, nose, lips, cheekbones, chin), vertex-painted (lips, brows, eye shadow, stubble, cavities, paint), with eyeballs set into the sockets, ears, orc tusks, argonian horns/frills; hair and beards are shells over the same grid. `SEEDS=2 cargo test --features dev heads -- --ignored` dumps heads to `screenshots/heads/*.bin` and `tools/heads.py ['Orc-*']` renders front/¾/profile sheets (`screenshots/heads/sheet.png`) in seconds — use it before in-game shots. `tools/fit [name]` (~6 s) matches the player against reference pictures: each `tools/fits/<name>.json` names a `ref images/` picture, a game pose (+ per-joint offsets) and a camera; the `humanoid::tests::fit` test poses and CPU-skins `dragonborn()` into `screenshots/fit/<name>.bin`, and `tools/fit.py` renders `screenshots/fit/<name>.png` (reference | model | 50% blend | model outline on reference). Camera-only changes need just `tools/fit.py <name>`.
- `npc.rs` — townsfolk: each town/city/farm layout gets villagers who appear within 320 m of the player, stroll between street points, stop and face the player, and answer E ("Talk") with a line. Up to 3 travellers walk the roads 110–240 m around the player (despawn past 420 m); most carry a lit torch at night (`Grip::Torch`, `humanoid::torch`, light + `Effects::torch`), some by day.
- `blocky.rs` — Blockbench-style low-poly kit: `Shape`s (`block`/`boxed`/`rod`, `frustum` (tapered box, wedge, pyramid), `prism` (n-sided cylinder, wheel, cone); `at`/`turned`/`along`/`placed`), each face a `Patch` packed into a pixel-art atlas sampled nearest; `Bone`s (part, parent, pivot) → `kits(bones, px, painters, glow, …)` builds the meshes once and one material per painter (`Fn(Skin, Pixel) -> Texel`, colour + emissive; `Pixel` helpers `edge`/`speck`/`shade`/`middle`). `knee` is two-bone IK, `aim` points a −Z-authored segment.
- `robot.rs` — a Blockbench-style robot (stilt legs, birdcage body with a floating ember core, CRT head with a pixel face, propeller cap, gramophone-horn arm, lantern claw): built with `blocky`; `Idle` animates the bones. Brasswick stands a few metres from `START`, turns toward the player and is the questgiver of "Fur for the Furnace" (`Errand`: bring 3 wolf pelts for 150 gold and an amethyst; talk with E).
- `patrol.rs` — Securitron-like road robots in four palettes (CRT face, siren, gatling arm, STOP sign) on four IK legs ending in wheels: ~36 roll along the main roads (over 300 m, one per 1.2 km, one starting near `START`), keep right, turn back at the ends; body pitch/roll follow the wheel contacts (`terrain::height_at`, bridge decks); hidden and not posed beyond 700 m.
- `spider.rs` — 7 giant (≈70 m leg span) pixel-art spiders roaming mountain slopes around the start valley (`HOMES`: high, not too steep, 500–2600 m from `START`, baked at startup), slow wander with pauses; eight two-bone IK legs stepping in alternating groups, body height and tilt fitted to the feet; glowing eyes and dorsal markings.
- `heli.rs` — helicopter on a concrete helipad (`PAD`: flattest clear spot 60–170 m from `START`, on a plinth over the slope; flora keeps off it) built with `blocky`. E boards (`player::Seated`: collider off, steering and attacks off, carried on the pilot seat by `ride` in the `Motion::seated` pose, visible through the hollow cabin's blended glass kit) and leaves once landed and slow. Left mouse fires the nose gatling (`shoot`: rays from the camera centre toward the crosshair, `Struck` on anything with `Vitals`, sparks elsewhere, emissive `Tracer`s from the muzzle). A crash (hit faster than `CRASH` or tipped over on the ground) `explode`s it: blast + light + `Cue::Explosion`, charred paint, burning and smoking `Wreck`, the player thrown out as a ragdoll (`Knocked`, or `Dead` if the blast kills); `salvage` puts a fresh one back on the pad after `WRECKED_FOR`. `Airframe::step` is the pure flight model: rotor spool, collective lever easing to the tilt-compensated hover setting (Space/Shift up, Ctrl down, rests at 0 on the ground), thrust along the tilted rotor axis with ground cushion, translational lift and thinning air, anisotropic + rotor drag, cyclic attitude springs (W/S pitch, A/D bank, auto-bank in yawing turns), mouse-steered tail rotor with weathervaning and torque kick, settling to the slope on the skids. `fly` moves the compound hull with `MoveAndSlide` (hard hits shake), `chase` places the camera (F: cockpit). `cargo test flight` checks the model end to end.
- `horse.rs` — static horse model (coats, mane, tail, optional saddle) used by the stables.
- `walker.rs` — kinematic character movement for anything with `Walker` + `Collider` (set `wish`, `facing`, `leap`, `shove`).
- `player.rs` — player, camera `View` resource, controls.
- `combat.rs` — `Vitals`, `Side`, `Fighter`, `Dead`, `Struck` message, `Shake`, `Stealth { sneaking, noticed }` (Ctrl toggles sneaking in `player.rs`: slower, crouched `Motion::crouch`, lower camera; foes' detection range shrinks with movement, darkness and facing away and `Foe::suspicion` builds up gradually; hits on unaware foes deal 3×; HUD eye opens with `noticed`).
- `creature.rs` — turns `FoeSpawn` into wolves/draugr/bandits, `Mind` AI, looting, valley encounters, and `GARRISONS` (fort/camp bandits, wild wolf packs) mustered when the player comes within 300 m. Bodies are tailored in background tasks (`Dressing`, reported as pending) so mustering doesn't hitch. `wolf.rs` — quadruped rig.
- `dragon.rs` — dragons: 18-bone rig (meshes built once, `Anatomy`), `Flight` state machine (arrive, circle, strafe with fire breath, land, fight, rise, fall, slain → soul absorbed). One arrives at the start (`dragon` opt); more live at `LAIR_SPOTS` (the highest separated peaks, baked; `cargo test lairs` checks them against the terrain): they roost and soar over their lair, wake when the player comes within `WAKE` (half when sneaking), and fly home (`Homing`) when the player strays past `LEASH`, dies or goes underground.
- `shout.rs` — Unrelenting Force (Z), word walls, soul wisps. `fx.rs` — bevy_hanabi particle `Effects`.
- `depths.rs` — underground dungeons behind load doors: every site barrow (`Depths::Tomb`) and wolf cave (`Depths::Cave`) has a `settlement::Entrance`; E there fades to black and moves the player into an interior `BELOW` m under it. `chart` lays out 5–7 rooms linked by passages, `carving` is their SDF, `hollow` meshes only the inner shell, `furnish_*` adds props, lights, foes (dormant draugr in sarcophagi, overlord, wolves or bandits) and a chest; raised with `cave::Kit`. Interiors are hewn in background tasks when the player is within 90 m (on wasm only on entering) and dropped when far away. A `Leave` door by the entry returns outside.
- `flora.rs` — trees, rocks, grass and scatter, sown per 64 m cell in background tasks within 1.3 km of the camera (the task also bakes merged far meshes and the compound collider; colliders only exist within 160 m). Steep upper slopes get `bluffs`: big (35–70 m) `model::crag` masses walking along the contour, faces turned downhill, kept off routes (`route_distance`; `road_distance` saturates at 24 m); snow on up-facing facets above the snow line. Bluffs are not part of the flora cells: `Crags` raises them for the whole world at startup in 256 m blocks (sampling `terrain::height_at` directly), each a `Stand` (carved LODs up close, merged hull meshes beyond ~320 m, so mountains are rocky to the horizon). Crags and bluffs use `Stuff::Cliff` (streaked rock texture + normal map; meshes need tangents). Smaller crags make the outcrops. `cave.rs` + `sdf.rs` — SDF-meshed Hollowcrag Barrow and Fellhound Den. `landmark.rs` — watchtowers and camps (one per `Place` with that marker), standing stones.
- `hud.rs` — compass (places within 380 m), bars, notices, prompts, intro. `inventory.rs` — `Item` (name/kind/value/weight/power), `Loot`, player `Inventory` (`take(loot)`), Tab/I menu. `audio.rs` + `audio/` — all sound synthesised at startup. Bevy's AudioPlugin is disabled: `audio/output.rs` plays the f32 takes itself (native: one cpal stream with a small mixer thread fed by a channel; web: WebAudio buffer sources with gain/pan nodes, mixed off the main thread). `Voices` tracks one-shots/loops with their anchor (flat, a point, or an entity) and re-pans them each frame.
- `work.rs` — incremental work that also paces single-threaded wasm. A `Work<T>` is a sequence of small steps (`once`, `rows(n, row)`, `.then`, `.map`); `spawn(work)` gives a `Job`, polled with `job.done()`. Native: a task-pool task, and at most 12 finished jobs are handed over per frame so integrating them can't pile up. Wasm: steps run in place inside `done()` until ~6 ms of step time is spent that frame (the first step always runs). Both unlimited in shot mode. Keep steps small by splitting heavy work into rows: terrain tiles, ground chunks (`Ground::filling`), flora cells (per 32 m patch), grass cells (per tuft row), settlements (4 works per job). `task(f)` = `spawn(once(f))`; `run(work)` does it all at once (tests, the first frame).
- `signal.rs` — shared messages/resources between modules: `Notice`, `Discovered`, `Prompt`, `Engaged`, `Sound { cue: Cue, at }`, `FoeSpawn { kind, dormant }` (spawn an entity with this + `Transform` and the creature module turns it into a creature), `WordWall`, `Shouts`.

Physics: avian3d. Exact vertical rays can miss the heightfield collider; tilt them slightly or use shape casts.
Lighting is physical: sun is `lux::RAW_SUNLIGHT`, exposure ev100 ≈ 13 outdoors by day, ≈ 6.2 at night, ≈ 7.6 underground; the eye adapts toward that smoothly (fast to bright, slow to dark). Emissive is NOT exposure-scaled: ~1–10 glows (see `Stuff::Frost`/`Ember`/`Cinder`), 50+ blows out to white. Point lights need ~100k+ lumens to matter outdoors, far less underground.

# Opts
Env var `SKYRIM` holds JSON5 `opts::Opts`: `hour` (start hour, 9.5), `day` (secs per day), `shot: <secs>` (screenshot to `screenshots/shot-$SHOT_NAME.png` then exit), `at: '<place name fragment>'` (spawn near that place), `yaw`, `pitch`, `turn` (camera yaw offset, deg), `zoom` (camera distance), `pose: 'swing'|'guard'|'dead'|'run'|'sneak'`, `intro`, `first` (first person), `inside: [x,y,z]` (spawn at a spot), `foe: 'wolf'|'draugr'|'overlord'|'bandit'|'chief'` (inert specimen in front of the player), `foe: 'patrol'` (parked road robot, `seed` picks the palette), `foe: 'spider'` (giant spider `gap` m ahead, default 45), `foe: 'dragon'|'dragonaloft'|'dragonslain'|'dragonfire'` (dragon posed in front; `dragonfire` breathes fire), `foe: 'cook'|'huntress'|'priest'|'farmer'|'sellsword'` (villager in front, `torch: true` to hand them a torch, `race: 'nord'|'orc'|'highelf'|'darkelf'|'argonian'`, `seed`, `gap` metres away; `first: true, pitch: 3, gap: 0.65` is a face portrait), `pilot: true` (start seated in the helicopter on its pad), `dragon: <secs>` (dragon arrival time, default 75), `delve: 'tomb'|'cave'` (start inside the dungeon of the nearest such site), `press: [[secs, 'Z'|'E'|'F'|'W'|'A'|'S'|'D'|'I'|'Tab'|'Enter'|'Escape'|'Up'|'Down'|'Space'|'Shift'|'Ctrl'|'LMB'|'RMB'], …]` (inject input: taps of 0.15 s), `hold: [[from, to, key], …]` (keep a key down between two times), `eye: [x, above_ground, z]` + `look: [x, above_ground, z]` (free debug camera; terrain, flora and settlements stream around it, grass and colliders stay around the player).
e.g. `SKYRIM='{shot: 5, at: "hollow"}' SHOT_NAME=barrow cargo run`. Screenshots are the way to check visuals — always look at them.

# Build
Priority is fast incremental builds over runtime speed. Debug builds only; release only when asked.
- `cargo check` to verify compilation; `cargo run --features dev` to test (`dev` = Bevy dynamic linking, incremental rebuild ~13 s vs ~21 s). `tools/shot <name> '<opts>'` builds and screenshots; `tools/shots name '<opts>' name '<opts>' …` builds once and takes several in a row under xvfb from a copy of that build (so editing code meanwhile is safe once the build step is done); `SHOT_TIMEOUT` (default 400 s) for heavy views like town interiors.
- `cargo test --features dev map -- --ignored` renders the whole world's height/paint/water top-down to `screenshots/map.png` in ~2 s (places in red, 500 m grid) — use it to check layout before spending minutes on screenshots. `cargo test --features dev plant_map -- --ignored --nocapture` (~30 s) plots every tree/rock/shrub onto `screenshots/plants.png` and prints counts per km². Screenshots wait for all streaming (`signal::Pending`) to settle; in shot mode flora stands are placed without the per-frame cap. While waiting the camera draws nothing (a 1 px viewport on an unused render layer, sun shadows off), then it renders until no pipelines are still compiling (at least 3 frames) and exits as soon as the PNG is written, so a shot takes ~1–1.5 min: ~7 s startup, ~50 s world generation, ~5 s per rendered frame under lavapipe.
- `tools/uesp <words>` finds Skyrim screenshots on the UESP wiki (`File:SR-*`, icons skipped) and saves them to `screenshots/uesp/`; `-p Skyrim:Whiterun` takes those shown on a wiki page; `-n` count, `--list` to only print. UESP's image host blocks scripts with a Cloudflare challenge, so downloads fall back to the same query on the Elder Scrolls Fandom wiki (`--fandom` goes there directly; some results are concept art). Use it to compare the look of a specific thing beyond `ref images/`.
- On a panic or startup failure (including Bevy system param conflicts), rerun with `RUST_BACKTRACE=1`.
- Cloud sessions have no GPU: wrap runs in `xvfb-run -a -s "-screen 0 1920x1080x24"` (lavapipe, software Vulkan). Frames are slow and the game clock is capped per frame, so it runs far behind real time: `shot: 3` takes ~1.5 min. Keep `shot` small and pair it with `intro: false`.
- Bevy and avian3d run without default features: `Cargo.toml` lists only what the game uses (no audio, gltf, scenes, gizmos, sprites, gamepads, webgl). Add a feature there when using a new Bevy part (e.g. `tonemapping_luts` for LUT tonemappers).
- Web build (GitHub Pages on master push): `trunk build --release`; release profile is thin LTO, one codegen unit (fat LTO runs out of memory), `wasm-opt -O3` (with the wasm features Rust emits enabled, e.g. bulk memory), `tracing` capped at warn. ~12 MB gzipped.
- Docs: https://docs.rs/bevy/0.19.1/bevy/

# Style
Code structure should mirror the thinking behind it: translate the user's conceptual framework fairly directly into code. Functional-ish.
- Format with `cargo +nightly fmt` (repo `rustfmt.toml` uses nightly-only options; stable rustfmt ignores them and reflows everything). Avoid comments; name things well.
- Order within a file: if A refers to B, A comes after B. Keep related code together.
- Semicolons are a verbosity signal: prefer expressions over statements.
- No `return`, `continue`, `let … else`, or early exits.
- Prefer let chains over nested `if let`/`if` or `.and_then()`. Chains can mix fallible and plain (irrefutable) lets:
  ```rust
  if let Some(weapon) = equipped
    && weapon.is_ranged()
    && let reach = weapon.range() * skill
    && let &Transform { translation, .. } = weapon.transform()
    && let Some(target) = find_target(translation, reach)
  {
    attack(target)
  } else if let Some(weapon) = equipped {
    melee(weapon)
  } else {
    flee()
  }
  ```
- Prefer `Option` methods over matching on `Option` (not so for most other enums).
- Prefer `find` (match a predicate), `find_map` (match and transform), `any`, `fold` over loops with break.
- Eagerly destructure: `let &Thing { field } = thing()` binds `field` by value, no `*field` later.
- Domain model with named instances, newtypes and associated consts.
- No more function-calls-function indirection than needed: inline, or use blocks or small local closures, when a helper would wrap a single call site.
